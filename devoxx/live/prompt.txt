For every pixel (x, y), with aspect = (float) width / height, set re = view.get(0) + (x / (float) width - 0.5f) * view.get(2) * aspect and im = view.get(1) + (y / (float) height - 0.5f) * view.get(2), iterate z = z*z + c with floats until |z| > 2 or maxIterations, and store the iteration count at out[y * width + x]. Use two nested @Parallel loops, y outer and x inner.
